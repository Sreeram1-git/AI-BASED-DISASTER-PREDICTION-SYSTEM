# AI-Based Disaster Prediction and Early Warning System

## Project Description
A beginner-level Python project that collects weather
data and performs basic weather risk classification.

## Technologies Used
- Python
- Open-Meteo API
- Requests
- Pandas
- Matplotlib
- CSV

## Features
- Fetches current weather data
- Stores weather history
- Displays weather graphs
- Performs basic risk classification
- Stores risk history

## Note
This is an educational prototype. Its risk thresholds
are illustrative and are not official disaster warnings.
